# Aufzeichnungen und Vorlagen

## Zweck

Dieses Dokument definiert verbindliche QMS-Aufzeichnungen und bietet kompakte Markdown-Vorlagen für wiederkehrende Nachweise.

## Aufbewahrung

| Aufzeichnung | Mindestaufbewahrung | Eigentümer |
| --- | --- | --- |
| Freigegebene QMS-Dokumente | solange gültig plus 3 Jahre | QMS-verantwortliche Person |
| Auditberichte | 3 Jahre | QMS-verantwortliche Person |
| CAPA-Nachweise | 3 Jahre nach Abschluss | QMS-verantwortliche Person |
| Risikoregister | aktuelle Version plus 3 Jahre Historie | Prozessverantwortliche |
| Schulungsnachweise | Beschäftigungsdauer plus 3 Jahre | Teamleitung / People Operations |
| Managementbewertung | 3 Jahre | Geschäftsführung |

## Vorlage: CAPA-Protokoll

| Feld | Inhalt |
| --- | --- |
| CAPA-ID | CAPA-YYYY-### |
| Quelle | Audit, Beschwerde, Abweichung, Kennzahl, Risiko |
| Beschreibung | Was ist passiert? |
| Sofortmaßnahme | Welche unmittelbare Korrektur wurde durchgeführt? |
| Ursachenanalyse | Methode und Ergebnis |
| Maßnahmen | Korrektur- und Vorbeugungsmaßnahmen |
| Verantwortlich | Rolle oder Person |
| Fällig | YYYY-MM-DD |
| Wirksamkeitskriterium | Messbare Abschlussbedingung |
| Abschlussbewertung | Ergebnis der Wirksamkeitsprüfung |

## Vorlage: Auditbericht

| Feld | Inhalt |
| --- | --- |
| Audit-ID | AUD-YYYY-### |
| Auditumfang | Prozess, Standort, Produkt oder Team |
| Kriterien | QMS-Dokumente, Normen, Anforderungen |
| Auditoren | Namen oder Rollen |
| Datum | YYYY-MM-DD |
| Zusammenfassung | Kurzbewertung |
| Feststellungen | Abweichungen, Beobachtungen, Stärken |
| Maßnahmen | Verweise auf CAPAs oder Aktionspunkte |

## Vorlage: Managementbewertung

| Abschnitt | Leitfragen |
| --- | --- |
| Qualitätsziele | Wurden Ziele erreicht? Welche Abweichungen bestehen? |
| Auditresultate | Welche Trends, Abweichungen und Stärken wurden festgestellt? |
| CAPA-Status | Welche CAPAs sind offen, überfällig oder unwirksam? |
| Risiken und Chancen | Haben sich kritische Risiken verändert? |
| Ressourcen | Sind Kompetenzen, Tools und Kapazitäten ausreichend? |
| Entscheidungen | Welche Maßnahmen, Verantwortlichen und Fristen wurden beschlossen? |
