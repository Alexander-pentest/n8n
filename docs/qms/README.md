# Qualitätsmanagementsystem (QMS)

Dieses Verzeichnis enthält ein schlankes, auditierbares Qualitätsmanagementsystem als Markdown-Dokumentation. Es ist als sofort nutzbare Vorlage gedacht und muss vor einer formalen Zertifizierung an Organisation, Produkte, regulatorische Anforderungen und geltende Normen angepasst werden.

## Dokumentenlandkarte

| Dokument | Zweck |
| --- | --- |
| [QMS-Handbuch](./quality-manual.md) | Beschreibt Geltungsbereich, Prozessmodell, Rollen und Kernprinzipien des QMS. |
| [Qualitätspolitik](./quality-policy.md) | Legt Qualitätsgrundsätze, Ziele und Verpflichtungen der Leitung fest. |
| [Dokumentenlenkung](./document-control.md) | Definiert Erstellung, Prüfung, Freigabe, Versionierung und Archivierung von QMS-Dokumenten. |
| [Risikomanagement](./risk-management.md) | Beschreibt Identifikation, Bewertung, Behandlung und Überwachung von Risiken. |
| [CAPA-Prozess](./capa.md) | Regelt Korrektur- und Vorbeugungsmaßnahmen bei Abweichungen. |
| [Interne Audits](./internal-audits.md) | Beschreibt Planung, Durchführung, Berichtswesen und Nachverfolgung interner Audits. |
| [Änderungsmanagement](./change-management.md) | Regelt Bewertung, Freigabe und Nachverfolgung von Änderungen. |
| [Schulung und Kompetenz](./training.md) | Definiert Kompetenzanforderungen, Einarbeitung und Schulungsnachweise. |
| [Aufzeichnungen und Vorlagen](./records-and-templates.md) | Listet verbindliche Aufzeichnungen und wiederverwendbare Vorlagen auf. |

## Empfohlene Nutzung

1. Einen QMS-Verantwortlichen benennen und in [QMS-Handbuch](./quality-manual.md#rollen-und-verantwortlichkeiten) dokumentieren.
2. Den Geltungsbereich prüfen und organisationsspezifisch ergänzen.
3. Dokumente nach [Dokumentenlenkung](./document-control.md) versionieren, prüfen und freigeben.
4. Erste Qualitätsziele in der [Qualitätspolitik](./quality-policy.md#qualitätsziele) festlegen.
5. Risiken und Chancen im [Risikoregister](./records-and-templates.md#vorlage-risikoregister) erfassen.
6. Auditprogramm, Schulungsplan und Managementbewertung terminieren.

## Mindestfrequenzen

| Aktivität | Mindestfrequenz | Verantwortlich |
| --- | --- | --- |
| Managementbewertung | jährlich | Geschäftsführung |
| Interne Audits | jährlich oder risikobasiert | QMS-Verantwortliche Person |
| Review kritischer Risiken | quartalsweise | Prozessverantwortliche |
| Review offener CAPAs | monatlich | QMS-Verantwortliche Person |
| Schulungsmatrix aktualisieren | halbjährlich | Teamleitung / People Operations |
